# 小小运动家

移动端优先的静态亲子运动网页，使用方式是“先选动作，再选动作阶段，再生成一次训练”。不按日期或星期排课。

## 页面逻辑

- 动作库按移动、控物、稳定、节奏组织。
- 每个动作有四个渐进阶段，可分别选择；拍球和投掷可以处在不同阶段。
- 本次最多选三个动作：第一个是主项，其余是配套动作。
- 训练自动生成“热身 → 主项 → 配套 → 合作游戏 → 收尾”。一次可以选择轻量、标准或加长时长。
- 同一动作会在本次训练中短回合重复，配套动作负责补充其他基础能力，避免把所有动作混成连续考核。
- 动作问号打开四步图解，支持逐步查看和播放。
- 勾选、动作阶段、时长、感受与备注保存在当前浏览器，可以在“陪练”中导出和导入备份。

## 4–6岁基础动作范围

网页当前包含：走停与变向、双脚跳与落地、单脚短暂支撑、侧向跨步、平衡走、投掷、接球、拍球、踢球与停球、跳绳准备、爬行与支撑。

这套范围参考教育部《3–6岁儿童学习与发展指南》健康领域、WHO 低龄儿童身体活动指南和 CDC 学龄前儿童活动建议。官方资料强调全天活动、适龄主动游戏、尊重个体差异，不把某个数量当作家庭训练达标线。网页中的分阶段动作是家庭实践方案，不是个体评估。

## 部署

上传以下文件即可，无需构建、后端或外部 CDN：

- `index.html`
- `styles.css`
- `content.js`
- `illustrations.js`
- `app.js`
- `assets/`

入口是 `index.html`；`运动计划.html` 是同步的备用入口，`qa/` 不需要上传。
