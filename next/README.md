# 小小运动家：简化预览

这是基于现有线上入口复制出的独立调整目录，旧的 `v2/` 文件和数据逻辑保持不变。

## 这次调整

- 训练页默认只呈现当前技能、当前叶子和一个开始按钮，技能、叶子数量与时长收进折叠面板。
- 一次练习只围绕一个技能，支持从同一棵树选择一到三片可练叶子。
- 训练过程一次只看一个动作画面和一个口令，完成四步后点亮叶子。
- 成长树使用独立的自然树形底图，根部、枝条和叶片状态分层呈现；锁定叶子可以先预览，记录集中在“我的”里的成长记录。
- 家长设置、档案切换、备份和陪练提示收进“我的”，孩子训练时不用处理复杂设置。
- 继续沿用手机优先、底部面板和折叠内容；当前目录使用独立的本机存储键，不会读取旧入口的记录。
