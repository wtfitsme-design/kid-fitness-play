# 小小运动家 v2 预览

这是在 v1.0 基础上的独立版本，不覆盖根目录线上版。

## 主要变化

- 一次训练只选择一个技能，围绕一条技能路径练习。
- 每项技能有独立技能树，叶子按前置能力逐步解锁。
- 叶子支持四步动作图解、点亮、文字记录和本机保存。
- 记录页按技能汇总成长进度，支持 JSON 导出和导入。
- 动作范围聚焦拍球、投掷、接球、踢球、跳绳、击打与挥拍、核心支撑；简单走跑跳只保留为热身。
- 页面按手机优先设计，技能树和叶子详情使用折叠和底部面板。

## 预览

进入 `v2/index.html`。无需构建，也不依赖外部 CDN。

## 插画校验状态

页面已为每片叶子配置四张图片，但部分叶子仍复用同一套技能级插画，动作语义尚未通过最终验收。集中在接球、跳绳、击打与挥拍、核心支撑，以及少数投掷叶子。发布前需要逐叶检查动作与图是否一致，并替换重复或错位的画面；文件存在和四步互不重复不代表插画语义正确。
